# V2.3 RC2 修正與驗收

修正 PDF 直接以 data URL 下載在手機可能無反應的開啟方式，改成使用者點擊時同步開啟 PDF Blob 預覽。拒絕非 PDF 附件並顯示訊息；彈出視窗被阻擋時提供提示。這不會修復已損壞或原先未存入的附件。

本機資料庫交易前檢查連線。若為已關閉的連線，重新開啟相同資料庫；不刪除資料、不重播已開始的寫入交易。還原保留 policies 與 settings 同一原子交易，失敗訊息留在備份區。快取升級 shell-4。

## 自動驗證

- `npm test`：16/16 通過，涵蓋既有行事曆與 Excel 規則、連線重開、PDF 預覽、無效附件及彈出阻擋。
- `NODE_PATH=/tmp/renewal-rc2/node_modules node tests/restore-recovery.cjs`（需安裝 fake-indexeddb）：模擬在選檔與寫入之前連線關閉，還原仍保留 PDF；設定寫入失敗時整批回滾，原保單不變。
- 以上為模擬測試，不等同 iPhone Safari 實機通過。

## 使用者需驗證

1. 使用原本 V2.3 入口重新整理，確認頁首 RC2；必要時關閉重開再整理，不清除網站資料。
2. 在既有保單按「開啟 PDF」，確認能預覽；如顯示附件格式錯誤，保留原始備份及 PDF，回報訊息。
3. 關閉頁面再開，確認保單仍在，再測備份／還原及附加 PDF。
4. Google 實際新增、修改、取消已由使用者回報通過；RC2 尚需回歸驗證，iPhone 實際通知送達尚未驗收。

原 V2.2 正式版未修改。手動 iCloud JSON 備份方式維持，沒有新增背景同步。
