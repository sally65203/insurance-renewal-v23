# V2.4 正式切換

- 先從原 App 下載最新 JSON 並手動存入 iCloud Drive。更新後從原本的主畫面圖示進入，核對保單筆數與 PDF。
- iPhone 續保推播需個別開通。先輸入開通碼、允許通知並傳送測試。收到測試通知前，請保留現有 Google 日曆提示。
- 測試成功後，在 iPhone 行事曆清單中，進入「產險續保提醒」旁的資訊頁，關閉該日曆的事件提示，再回 App 啟用正式保單推播。若啟用失敗，重新開啟該日曆的事件提示。
- 正式推播只同步一部裝置。改期或取消後，App 會在連線時更新排程。Google 事件及既有設定可用於回復，停用 App 推播後，可重新開啟舊日曆的事件提示。
- 推播會把本機識別碼、車牌、險種與日期傳到 Supabase。保單姓名、保單號碼、保費和 PDF 仍由 App 在裝置保存。
