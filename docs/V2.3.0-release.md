# V2.3.0 正式版發布紀錄
日期：2026-11-05（Asia/Taipei）

## 發布內容
由已驗收的 V2.3 RC2 功能版本發布。Google Calendar 方案 A：開啟系統並授權後同步；保單異動及匯入後同步；到期前一個曆月建立提醒，支援新增、修改、取消、去重與失敗重試。手機關閉系統時不背景同步新異動，已建立事件由行事曆提醒。

Excel 清冊欄位對應與去重規則保留；PDF Blob 預覽及資料庫連線恢復修正保留；iCloud Drive 為手動 JSON 備份還原，不是自動雲端資料同步。

## 驗收依據
- 使用者實機回報：Google 同步失敗 0 筆、iPhone 內建行事曆通知送達、取消提醒移除、PDF 開啟、重開保存、最新 JSON 備份。
- 最後兩項原待驗內容：使用者確認新主畫面 App 完整資料與原全天提醒均正常。
- 自動測試：16/16 回歸通過；詳細測試範圍與歷史驗收見 [驗收報告](V2.3-acceptance-2026-11-05.md)。
- Excel 私有清冊 87 筆測試為前期開發結果，本次發布不宣稱再次重跑私有原檔。
- Google 限流、斷網與 token 失效等錯誤路徑以模擬測試為主，不宣稱每項均有真實 API 故障注入。

## 更新方式
1. 保留最新 JSON 備份及 V2.2 舊圖示。
2. 沿用現有「續保 V2.3」圖示；關閉重開，必要時於相同入口重新整理，確認頁首「V2.3 正式版」。
3. 無需刪除 App、清除網站資料或重新匯入完整清冊；本次資料庫名稱／版本、網址、manifest id／scope／start_url 不變。
4. 若 Google 授權已過期，按連接 Google；同步後確認失敗 0 筆。
5. 重要資料異動後，下載 JSON 至 iCloud Drive。V2.2 及不同入口不自動合併。

## 已知使用限制
- token 僅存記憶體，可能需重新授權；ID 設定留在目前瀏覽器環境。
- 通知受行事曆同步、帳戶、手機通知與專注模式等設定影響；全天通知時刻須以個人裝置設定及實際結果為準。
- 不提供跨裝置保單雙向雲端同步；固定單一入口管理同一專用日曆。
- 每年需匯入／核對當年度清冊，舊保單續保完成後人工標為已續保；不自動延長一年。沿用相同公司／險種／保單號碼時注意去重略過原因。
- JSON 含附件及個資、未加密，需妥善保存；CSV 不可取代 JSON 還原。
